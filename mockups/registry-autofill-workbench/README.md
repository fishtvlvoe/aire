# AIRE 地政自動填寫工作台 Demo

這是 `disclosure-registry-autofill-system-update` 的 UI/UX 草圖，先用靜態 HTML 對焦分類與工作台版型。

## 檔案

- `index.html`: 可直接用瀏覽器開啟的互動前靜態 mockup。

## 設計重點

- 一級選單改成接近 OPCOS 的資料夾式下拉：案件管理、地政資料、產出文件、系統設定。
- 說明書工作台內再分：欄位、地政來源、補件、費用、PDF 檢查。
- 章節分類改用下拉選擇與單一摘要卡，避免全部章節同時展開。
- 右側面板負責解釋目前選取欄位的來源、缺口、API 狀態與費用。
- 費用紀錄與 COP309 失敗不計費先放進介面，避免後續只做資料表而客戶看不懂。
- 狀態色簡化為灰階為主，只保留 AIRE 主色標示目前選取或成功帶入。
