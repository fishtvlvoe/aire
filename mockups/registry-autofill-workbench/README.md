# AIRE 地政自動填寫工作台 Demo

這是 `disclosure-registry-autofill-system-update` 的 UI/UX demo，先用靜態 HTML 對焦分類、欄位審核、費用紀錄、升級功能與屋主資料邊界。

## 檔案

- `index.html`: 可直接用瀏覽器開啟的高保真靜態 demo。

## 設計重點

- 一級選單維持 OPCOS 風格的資料夾下拉，Basic 只顯示案件、地政資料、產出文件與系統設定。
- 升級功能不放在 Basic 主選單；未升級時只在系統設定/右側面板顯示灰色開關，升級後才新增 Google 地圖、空拍/街景、AI 格局圖等完整資料夾選單。
- 主工作區重做成三欄：案件與章節、欄位審核、資料邊界與升級。
- 欄位審核直接呈現值、來源、狀態與下一步，讓 API 成功、失敗、未串接、人工補件可以同頁判斷。
- 費用紀錄以服務、結果、費用三欄顯示；COP309 這類失敗要清楚標成 0 元或不計費。
- 私人屋主姓名不做網路反查；只能由屋主提供、正式謄本 OCR 或人工輸入。
- MOI_API_009 只用於「已知姓名」比對，不能拿來找出屋主是誰。
- 空拍圖、地標圖、地籍圖、原有格局圖都保留 PDF slot；地政費用由客戶 MOI/COP 帳號負擔，其他升級服務由 AIRE 方案或另計處理。
