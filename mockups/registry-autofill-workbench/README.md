# AIRE 地政自動填寫工作台 Demo

這是 `disclosure-registry-autofill-system-update` 的 UI/UX demo，先用靜態 HTML 對焦分類、欄位審核、費用紀錄、升級功能與屋主資料邊界。

## 檔案

- `index.html`: 可直接用瀏覽器開啟的高保真靜態 demo。
- `settings.html`: 系統設定頁 demo，放授權升級、資料邊界、費用歸屬與 PDF 圖資位置。

## 設計重點

- 一級選單維持 OPCOS 風格的資料夾下拉，基本方案只顯示案件、地政資料、產出文件與系統設定。
- 一級選單頂部有收合按鈕；底部是客戶頭像與個人設定入口，不放方案說明文字。
- 升級功能不放在基本方案主選單；未升級時只在系統設定顯示灰色開關，升級後才新增 Google 地圖、空拍/街景、AI 格局圖等完整資料夾選單。
- 主工作區只保留兩欄：案件與章節、欄位審核。
- 欄位審核直接呈現值、來源與狀態，讓客戶只看到需要確認或補件的資訊。
- 費用明細放在「地政資料 → 費用紀錄」，系統設定只保留費用歸屬規則；地政查詢失敗要清楚標成 0 元或不計費。
- 私人屋主姓名不做網路反查；只能由屋主提供、正式謄本 OCR 或人工輸入。
- 所有權人比對服務只用於「已知姓名」比對，不能拿來找出屋主是誰。
- 空拍圖、地標圖、地籍圖、原有格局圖都保留 PDF 位置；地政費用由客戶的地政查詢帳號負擔，其他升級服務由 AIRE 方案或另計處理。
- 屋主資料邊界、升級開關、PDF 圖資位置這些低頻設定不常駐在案件工作台，只在設定或專用頁面出現。
