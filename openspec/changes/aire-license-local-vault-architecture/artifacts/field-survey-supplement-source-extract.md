## UI 分層決策

| 層級 | 用途 | 不應混入 |
| --- | --- | --- |
| 案件建立 / 基本資料 | 建立案件、拉謄本、確認建號地號、帶入可自動取得的基本欄位 | 不放整份現場調查表 |
| 草稿版說明書 | 缺資料留空白，讓業務帶去現場手寫 | 不顯示 `待補`，不塞過多說明文字 |
| 現場必問工作台 | 業務現場問屋主、拍照、記優缺點 | 不覆蓋謄本帶入的固定資料 |
| 秘書後補工作台 | 簽委託後，回公司補合約、謄本、圖資、照片命名與一致性檢查 | 不重新建立案件 |

## 建物版欄位母表

`建安不動產欄位總表_建物版.docx` 顯示，建物版母表涵蓋：

- 封面與識別：物件名稱、物件編號、案件類型、公司資訊、製表日期。
- 基本資料：建號、門牌地址、坪數、主建坪、附屬建物坪、共有部分坪數、樓層、總樓層、格局、社區名稱、建設公司、電梯數、每層幾戶、車位、座向。
- 權利與登記：所有權人、權利範圍、持分比例、他項權利、抵押、查封、限制登記。
- 使用與管理：用途、現況、管理方式、管理費、租金、帶看、鑰匙保管。
- 停車與設備：車位權屬、車位型式、車位位置、設備狀況。
- 瑕疵與風險：漏水、壁癌、增建、頂加、外推、夾層、凶宅 / 事故。
- 交易條件：委託總價、單價、土地增值稅、契稅、房屋稅、地價稅、稅費總額、代書費、其他費用。
- 周遭環境：最近學校、公園、市場、商圈、交通條件、周邊機能。
- 行情與附錄：成交行情、透明房價、附錄照片。

## 現場必問：類型差異

### 大樓華廈

- 總戶數、每層幾戶、電梯數、公設比、管理費金額。
- 管理方式、管理單位名稱。
- 車位形式、車位權屬、車位是否獨立。
- 集中收包裹、健身房、垃圾集中位置。
- 住商混合、中繼水箱、機房、樓中樓、挑高、其他特殊條件。

### 公寓

- 頂加、鐵皮、外推、違建、夾層及位置。
- 樓梯間使用狀況、管委或共管、共用陽台。
- 水表、電表、瓦斯是否獨立。
- 屋頂防水、隔音、整層出租、分租戶數。
- 公共空間使用權與維護狀況。

### 透天別墅

- 騎樓、騎樓面積、車庫寬深、可停幾台車、並排或前後。
- 前院、後院、側院。
- 樓層用途分配，主臥、客廳、神明廳、廚房所在樓層。
- 孝親房、夾層、頂夾、高度。
- 臨路面寬、巷寬或路寬、角地、雙面臨路、無尾巷、道路寬敞。
- 漏水、壁癌、屋頂防水問題。

### 店面

- 店面寬、深度、臨路寬。
- 角間、正三角窗、逆三角窗。
- 門前停車、騎樓、退縮空地、招牌可否掛。
- 店住混合、三相電、樓高、一樓挑高、夾層高度。
- 空店 / 出租中 / 營業中，租約到期、帶看時段。
- 周遭人流、車流、主要商圈名稱。

### 套房

- 獨立門牌、分租、獨立衛浴、全套或半套。
- 獨立水表、電表、租補資格。
- 租客、租期、短租、長租、學生租、上班族租。
- 隔間材質、公共區監視器、投幣洗衣機、飲水機。
- 電梯、電梯公斤數與維護單位、消防逃生。

### 農舍

- 合法農舍、土地與建物權屬是否分開、農用資格、農用限制。
- 灌溉、排水、供水、供電、台電、臨時電。
- 產業道路 / 計畫道路 / 繼承道路，農路幾米。
- 農舍一樓面積、周邊使用狀況。
- 農作物、果樹、溫室。
- 住家、休閒、工作室用途與合法性。

### 廠房

- 三相電、電壓、電力容量。
- 挑高、樑下高度、天車。
- 貨車 / 聯結車進出、臨路幾米、門寬、門高。
- 回車道、回車區、卸貨平台、碼頭、回車空間。
- 地坪承重、消防設備、排煙、排水、排污。
- 使用分區、合法用途、甲 / 乙 / 丙種工業地。
- 分租、立即使用、雜物機具、噪音、環評限制、鄰損限制。

## 實作要求

1. 案件建立只收最小必要資料與謄本查詢條件。
2. 拉謄本後要顯示「可帶入不動產說明書的欄位預覽」，不能只看到地號 / 建號。
3. 現場必問要做成獨立工作台或獨立區塊，不要塞進基本資料頁。
4. 秘書後補要做成簽委託後的第二階段工作台，沿用同一份 Page Contract，不另建一套 PDF 模型。
5. 每個欄位都要有來源標記：謄本 / API / 現場 / 合約 / 秘書後補 / 手填。
6. API 有資料的欄位直接帶入；沒有資料就留空白，禁止輸出 `待補`。
