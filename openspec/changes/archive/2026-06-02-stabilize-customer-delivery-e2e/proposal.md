# stabilize-customer-delivery-e2e

## Problem

完整 Playwright E2E 目前不是綠燈：58 筆測試中 44 筆通過、14 筆失敗。核心真實預查與 PDF 下載路徑已通過，但客戶交付前不能把完整 E2E 的紅燈留著。

失敗項目分成兩類：

- 測試期待仍停在舊路由、舊 tab 名稱、舊文案。
- 正式扣款、升級入口、品牌設定、免費預查結果顯示等交付流程需要確認現況是否符合產品預期。

## Goal

- 讓客戶交付前的完整 Chromium E2E gate 回到可判讀狀態。
- 測試只檢查現行產品 contract，不再卡在已淘汰的 `/cases/_?caseId=`、`補件/現場`、`資料來源` tab 等舊介面。
- 對真正的產品流程問題保留清楚驗收，不用放寬測試掩蓋問題。

## Non-Goal

- 不重設既有 UI/UX。
- 不重構案件、PDF、地政查詢架構。
- 不把完整 E2E 的真實資料測試改成 mock-only。
