# UI SDD: House Disclosure Workbench Boundaries

日期：2026-05-21

目的：定義下一個可驗收實作切片的 UI 邊界，避免案件建立、拉謄本、草稿預覽、現場必問、簽委託後補件再次打架。

## 核心原則

1. 案件建立頁只做最小輸入與拉謄本。
2. 拉謄本後立刻顯示可帶入欄位預覽，使用者不能等到 PDF 才知道抓到什麼。
3. 現場必問是獨立工作台，給業務帶去現場問、寫、拍。
4. 秘書後補是簽委託後的第二階段工作台，負責合約、謄本、圖資、照片命名與一致性檢查。
5. 預覽與下載 PDF 永遠讀同一份 Page Contract。
6. 客戶案件資料只留本機，不上傳雲端。

## UI Surface 1：案件建立 / 拉謄本

使用者目的：

- 建立案件。
- 選房屋 / 土地。
- 輸入查詢謄本所需條件。
- 觸發地政 API。

畫面應包含：

- 案件名稱 / 案號。
- 房屋 / 土地切換。
- 地段、地號、建號等查詢欄位。
- 拉謄本按鈕。
- 拉取狀態、扣款狀態、錯誤訊息。

不應包含：

- 38 題現況調查表。
- 完整現場必問清單。
- 秘書後補欄位。
- PDF 編輯器式 UI。

## UI Surface 2：謄本資料預覽

使用者目的：

- 知道系統實際抓到了哪些資料。
- 知道哪些資料會自動帶入不動產說明書。
- 知道哪些欄位缺資料，要現場問或回來補。
- 可以另存謄本資料供未來使用。

建議分組：

- 土地標示部。
- 土地所有權部。
- 建物標示部。
- 建物所有權部。
- 他項權利 / 限制登記。
- 可帶入說明書欄位。
- 目前空白欄位。

欄位列格式：

| 欄位 | 讀到的資料 | 帶入位置 | 來源 | 狀態 |
| --- | --- | --- | --- | --- |
| 所有權人 | 王小明 | 建物標示 / 所有權人 | 謄本 | 已帶入 |
| 建築完成日 | 2015-06-15 | 建物標示 / 屋齡 | 謄本 | 已帶入 |
| 主建坪數 | 空白 | 建物標示 / 主建坪數 | 謄本 | 待現場或後補 |

PDF 規則：

- UI 可以顯示「待現場或後補」幫使用者理解。
- PDF 不輸出 `待補`，只留空白或手寫線。

## UI Surface 3：現場必問工作台

使用者目的：

- 業務拿著草稿到現場，依房屋類型詢問屋主。
- 記錄優點、缺點、現況、管理、租約、照片。
- 補足網路查不到、謄本抓不到的資訊。

欄位來源：

- `field-survey-supplement-source-extract.md`
- `0520/不動產說明書/10-房屋-現況調查表-*.JPG`
- `0520/不動產說明書/11-房屋-生活機能.JPG`
- 共通欄位：委託總價、車位、地址、座向、用途、現況、租金、管理、社區、生活機能。
- 類型欄位：大樓華廈、公寓、透天別墅、店面、套房、農舍、廠房各自顯示。

圖片上傳標籤：

- 公司 Logo。
- 格局圖 / 土地規劃圖。
- 建物外觀照片。
- 位置圖 / 周邊圖。
- 現場調查照片。

不得把每個圖片區都叫「格局圖」。

## UI Surface 4：秘書後補工作台

使用者目的：

- 簽委託後，把手寫內容、合約條件、謄本核對、照片整理補回系統。
- 產生正式版不動產說明書。

畫面應包含：

- 共通後補欄位：建號、權狀坪數、主建物、附屬建物、共有部分、他項權利、樓層、用途、建築完成日、租客 / 租期 / 押金、合約條件、照片命名、591 / DM / FB / 說明書一致性檢查。
- 類型後補欄位：依房屋類型顯示。
- 右側或下方預覽：固定模板 PDF 預覽。

資料規則：

- 不建立第二套 PDF schema。
- 所有補件資料都回寫同一份 Page Contract。
- 預覽 iframe 和下載 PDF 必須一致。

## Entitlement Gating

Basic：

- 可拉謄本、保存、預覽。
- 可手動補資料。
- 可手動上傳圖片。
- 可匯出草稿 / PDF。
- 不可使用自動實價登錄、周邊行情、地籍圖、空拍、街景、格局圖處理。

Pro：

- Basic 加上實價登錄、周邊行情、位置圖 / 周邊圖、地籍圖。

Advanced：

- Pro 加上空拍圖、街景 / 外觀參考、格局圖處理、未來 104 / 社群 / DM / 591。

## 驗收清單

- 拉謄本後可以看到所有可帶入欄位，不只地號 / 建號。
- 重新開啟案件後，謄本預覽仍存在。
- 現場必問不在案件建立頁。
- 秘書後補不需要重建案件。
- 圖片上傳名稱符合該頁用途。
- Basic 可以手動上傳，但看不到或不能按進階 API。
- PDF 沒有 `待補`。
- 預覽與下載 PDF 內容一致。
- 客戶地址、地號、所有權人、謄本 payload 不上傳雲端。
