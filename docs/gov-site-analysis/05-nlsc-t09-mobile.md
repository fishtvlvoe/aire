# 國土測繪圖資服務雲（行動版 T09）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://maps.nlsc.gov.tw/T09/mobilemap.action |
| 所屬機關 | 內政部國土測繪中心 |
| 系統名稱 | 國土測繪圖資服務雲（行動版） |
| 類型 | 行動裝置 WebGIS 圖台 |

## 功能概述

國土測繪圖資服務雲的行動裝置版本，提供與桌面版相同的圖資瀏覽與查詢功能，但針對手機/平板介面優化。整合臺灣通用電子地圖、國土利用現況調查成果圖、基本地形圖、地籍圖等核心基礎圖資。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 支援地號查詢定位（需申請地籍 API） |
| **建號** | ⚠️ 間接 | 透過地籍圖層屬性查詢 |
| **地段** | ✅ | 可透過行政區定位 |
| **地址/門牌** | ✅ | 支援門牌定位查詢 |

## 操作方式

1. 開啟網頁（自動偵測行動裝置）
2. 上方搜尋列輸入門牌地址或地號
3. 系統自動定位並顯示地籍圖資
4. 可切換多種底圖（電子地圖、正射影像等）
5. 點選圖面可查看屬性資訊

## 憑證需求

| 項目 | 需求 |
|------|------|
| 基本圖資瀏覽 | **不需要**登入 |
| 地籍圖磚/地籍 API | **需申請**（限政府機關、國營機構、學術單位） |

## API / 開放資料狀況

### 免申請服務（Open Data）

| 服務類型 | 圖資內容 |
|----------|----------|
| WMTS | 臺灣通用電子地圖（比例尺 < 1:18,000）、國土利用現況調查成果圖 |
| WMS | 基本地形圖、行政區界圖 |
| 開放 API | 22 項免申請 API |

**免申請 WMTS 端點**：
```
https://wmts.nlsc.gov.tw/wmts
```

### 需申請服務（Restricted）

| 服務類型 | 圖資內容 | 申請資格 |
|----------|----------|----------|
| 地籍圖磚 WMTS | 有地號標註的地籍圖 | 政府機關、國營機構、學術單位 |
| 地籍 API | 指定地號查詢地籍圖 | 同上 |
| 門牌檢索 API | 模糊檢索門牌 | 同上 |
| 全國門牌地址定位服務 | 地址轉座標 | 同上 |
| WFS | 地籍圖、通用電子地圖向量資料 | 同上 |

### 申請方式

1. 至 https://maps.nlsc.gov.tw/S09SOA/ 下載申請書
2. 備函送至內政部國土測繪中心
3. 3 個工作天內通知審查結果
4. 聯絡窗口：圖資應用推廣科 林先生 (04)22522966#310

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| 地籍圖磚 | 可於地圖上顯示地籍圖層 |
| 門牌定位 API | 地址轉座標，再反查地號 |
| 地籍 API | 地號查詢取得地籍圖形 |
| 免費底圖 | 通用電子地圖可作為產品底圖 |

## 限制與注意事項

1. **地籍相關 API 需申請**，一般民間企業可能無法取得
2. 民營機構僅能申請「門牌 API」及「路徑規劃 API」
3. 地籍圖 WFS 與地籍圖 API 測量服務僅限內網使用
4. SSL 憑證有問題
