# 地籍圖資網路便民服務系統（Z10Web 新版）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://easymap.moi.gov.tw/Z10Web/Normal |
| 所屬機關 | 內政部資訊中心（系統維運） |
| 系統名稱 | 地籍圖資網路便民服務系統（Z10Web） |
| 類型 | WebGIS 圖台（OpenLayers + Cesium 3D） |

## 功能概述

Z10Web 是地籍圖資網路便民服務系統的**新版圖台**，相較於 R02 舊版，介面採用現代化 Bootstrap 5 設計，並加入 3D 模式（Cesium）。

提供地號查詢、門牌查詢、實價查詢、路徑導航、螢幕匯出等功能。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 支援完整地段地號查詢 |
| **建號** | ✅ | 支援建號查詢 |
| **地段** | ✅ | 先選縣市→鄉鎮→地段 |
| **地址/門牌** | ✅ | 支援門牌地址查詢 |

## 操作方式

1. 進入系統無需登入
2. 左側選單「查詢定位」
3. 可切換查詢類型：地籍查詢、門牌查詢、坐標查詢
4. 3D 模式可切換立體建物顯示
5. 進階功能包含實價查詢、路徑導航

## 憑證需求

| 項目 | 需求 |
|------|------|
| 查詢 | **不需要**登入 |
| 資料下載 | 無需登入 |

## API / 開放資料狀況

### 前端架構

系統前端使用 Vue.js（chunk-vendors.js）與 OpenLayers，包含以下模組：

| 模組 | 功能 |
|------|------|
| `qtDoorplate.js` | 門牌查詢 |
| `qtRoadSelect.js` | 道路選擇 |
| `qtRoadPath.js` | 路徑規劃 |
| `qtPlus.js` | 進階功能 |

### API 推測

Z10Web 與 R02 共用相同的後端 API（因為同網域），推測 API 端點與 R02 相同：

- `Map_json_getMaxMinLandNo`（地號查詢）
- `Door_json_getDoorList`（門牌查詢）

### 圖資服務

| 服務 | URL |
|------|-----|
| WMTS 底圖 | `https://wmts.nlsc.gov.tw/wmts` |

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| 地號→門牌對照 | 與 R02 相同的核心功能 |
| 3D 建物檢視 | 可視化建物位置與形狀 |
| 實價整合 | 圖台內可直接查詢實價登錄 |
| 路徑導航 | 可規劃至標的物的路線 |

## 限制與注意事項

1. **無官方公開 API 文件**
2. 與 R02 共用後端，API 需逆向工程
3. 3D 模式需較高的網路頻寬與瀏覽器效能
4. SSL 憑證有問題
