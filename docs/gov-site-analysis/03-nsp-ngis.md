# 國土規劃地理資訊系統（NGIS）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://nsp.nlma.gov.tw/ngis/ |
| 所屬機關 | 內政部國土管理署城鄉發展分署 |
| 系統名稱 | 國土規劃地理資訊系統 |
| 類型 | WebGIS 圖台（ArcGIS） |

## 功能概述

提供國土規劃地理資訊圖台功能，民眾不需登入即可查詢都市計畫、非都市土地、國家公園、各項環境敏感地區圖資、各項災害潛勢及防救災圖資。

圖台功能包括：切換各種底圖、查詢圖資屬性、製作統計地圖、統計分區面積、上傳本機圖層、瀏覽街景、GPS 定位及列印等。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 透過「國土測繪中心地籍查詢」功能查詢 |
| **建號** | ⚠️ 間接 | 地籍查詢可能回傳建號資訊 |
| **地段** | ✅ | 可透過行政區定位 |
| **地址/門牌** | ✅ | 支援定位查詢 |

## 操作方式

1. 進入系統無需登入
2. 上方選單「整合查詢」→「國土測繪中心地籍查詢」
3. 或「整合查詢」→「定位查詢」輸入門牌/地號
4. 點選圖面可進行屬性查詢
5. 可切換多種底圖（正射影像、通用電子地圖等）

## 憑證需求

| 項目 | 需求 |

## API / 開放資料狀況

### ArcGIS REST Services

系統使用 ArcGIS JavaScript API 3.35。從原始碼可發現以下資訊：

- `layerToken` 為動態產生（頁面載入時由伺服器注入）
- 底圖與圖層服務與國土測繪圖資服務雲共用
- 地籍查詢功能應是呼叫國土測繪中心 API

### 圖層清單（部分）

系統提供多種圖層，包含：
- 都市計畫使用分區
- 非都市土地使用分區/編定
- 國家公園
- 環境敏感地區（斷層、土石流、淹水潛勢等）
- 國土功能分區分類

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| 環境敏感地 | 可查詢斷層帶、土石流、淹水潛勢等（不動產說明書必備） |
| 國土功能分區 | 國土計畫法相關分區資訊 |
| 災害潛勢 | 可作為不動產說明書「災害」章節參考 |

## 限制與注意事項

1. 地籍圖資料與地政事務所現況資料存在時間差
2. 環境敏感地區圖資「僅供參考」，不得作為任何形式證明或主張
3. 全國災害潛勢圖因測製機關、測繪規範不同，與其他圖資套疊會有差異
4. 無公開 REST API，自動化需解析前端呼叫方式
