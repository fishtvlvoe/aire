# 實價登錄開放資料下載平台

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://plvr.land.moi.gov.tw/DownloadOpenData |
| 所屬機關 | 內政部地政司 |
| 系統名稱 | 不動產成交案件實際資訊資料供應系統 - Open Data |
| 類型 | 開放資料下載平台 |

## 功能概述

提供實價登錄**開放資料免費下載**，無需登入即可取得。資料包含完整地號與門牌之不動產成交資訊，格式包含 CSV、JSON、XML。

資料按月/季/年更新，可選擇特定縣市或全國資料。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 資料欄位包含完整地號 |
| **建號** | ✅ | 資料欄位包含建號 |
| **地段** | ✅ | 資料欄位包含地段名稱 |
| **地址/門牌** | ✅ | 資料欄位包含完整門牌 |

## 操作方式

1. 進入頁面無需登入
2. 選擇資料類型（買賣/租賃/預售）
3. 選擇縣市（可選全國或單一縣市）
4. 選擇日期範圍
5. 選擇檔案格式（CSV/JSON/XML）
6. 直接下載壓縮檔

## 憑證需求

| 項目 | 需求 |
|------|------|
| 資料下載 | **不需要**登入，完全免費 |

## API / 開放資料狀況

### 開放資料規格

| 項目 | 說明 |
|------|------|
| 授權條款 | 政府資料開放授權條款 |
| 格式 | CSV、JSON、XML |
| 更新頻率 | 每月 |
| 費用 | 免費 |

### 資料欄位（買賣案件）

主要欄位包含：
- 交易標的（土地/建物/車位）
- 鄉鎮市區
- 交易標的門牌 / 地號
- 交易年月日
- 交易筆棟數（土地筆數、建物棟數、車位個數）
- 移轉層次
- 總樓層數
- 建物型態
- 主要用途
- 主要建材
- 建築完成年月
n- 建物移轉總面積（平方公尺）
- 建物現況格局（房/廳/衛）
- 有無管理組織
- 總價元
- 單價元/平方公尺
- 車位類別/價格/面積
- 備註

### 無即時 API

目前僅提供**檔案下載**，無 REST API 可即時查詢單筆資料。

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| **歷史成交價格** | 可查詢特定地號/門牌的實價登錄歷史 |
| **市場行情** | 統計特定區域的成交均價 |
| 不動產說明書 | 可補充「周邊實價行情」章節 |

## 限制與注意事項

1. **無即時 API**，需定期下載全量資料檔案
2. 資料有延遲（約 1 個月）
3. 單筆查詢需在本機建立資料庫索引
4. 門牌與地號資料為成交當時資料，可能與現況不同
5. SSL 憑證有問題
