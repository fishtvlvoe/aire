# 地籍圖資網路便民服務系統（W10Web 地政司版）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://easymap.land.moi.gov.tw/W10Web/Normal |
| 所屬機關 | 內政部地政司 |
| 系統名稱 | 地籍圖資網路便民服務系統（W10Web） |
| 類型 | WebGIS 圖台（OpenLayers + Cesium 3D） |

## 功能概述

W10Web 是地政司維運的版本，與 Z10Web（資訊中心版）功能相似但導覽列設計不同。提供查詢定位、開發區查詢、統計儀表板、路徑導航、實價查詢、3D 模式等功能。

系統連結了各地政電傳系統（全方位電傳系統），可從「其他系統」選單進入各縣市地政系統。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 支援完整地段地號查詢 |
| **建號** | ✅ | 支援建號查詢 |
| **地段** | ✅ | 先選縣市→鄉鎮→地段 |
| **地址/門牌** | ✅ | 支援門牌地址查詢 |

## 操作方式

1. 進入系統無需登入
2. 上方導覽列「查詢定位」
3. 左側輸入查詢條件（地號/門牌）
4. 「開發資訊」可查詢都市更新、區段徵收等開發區
5. 「進階操作」包含實價查詢、路徑導航
6. 「其他系統」可連結至各縣市地政電傳系統

## 憑證需求

| 項目 | 需求 |
|------|------|
| 查詢 | **不需要**登入 |
| 電子謄本 | 需至各縣市地政系統（通常需憑證） |

## API / 開放資料狀況

### 前端架構

與 Z10Web 相同，使用 Vue.js + OpenLayers + Cesium：

| 模組 | 功能 |
|------|------|
| `qtDoorplate.js` | 門牌查詢 |
| `qtRoadPath.js` | 路徑導航 |
| `qtPlus.js` | 進階功能 |

### 圖資服務

| 服務 | URL |
|------|-----|
| WMTS 底圖 | `https://wmts.nlsc.gov.tw/wmts` |
| 地籍圖 | 內政部地政司提供 |

系統提供以下縣市地政電傳系統入口：

| 縣市 | 網址 |

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| 地號→門牌對照 | 核心功能 |
| 開發區查詢 | 可查詢都市更新、區段徵收等資訊 |
| 各縣市地政連結 | 可取得更詳細的地政資料 |
| 實價整合 | 圖台內可直接查詢實價登錄 |

## 限制與注意事項

1. **無官方公開 API 文件**
2. 各縣市地政電傳系統通常需要自然人憑證或工商憑證登入
3. 電子謄本需付費申請
4. SSL 憑證有問題
