# 國土測繪圖資服務雲介接服務說明（SOA/API）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://maps.nlsc.gov.tw/S09SOA/homePage.action?Language=ZH |
| 所屬機關 | 內政部國土測繪中心 |
| 系統名稱 | 國土測繪圖資服務雲介接服務說明 |
| 類型 | API 文件與服務目錄 |

## 功能概述

這是**國土測繪圖資服務雲的 API 文件入口**，列出所有可介接的圖資服務。服務分為「免申請」與「需申請」兩大類，包含 WMS、WMTS、WFS、REST API 等。

全站提供 200 餘種圖資、880 餘個圖層。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 地籍 API（需申請） |
| **建號** | ⚠️ 間接 | 地籍圖層屬性 |
| **地段** | ✅ | 行政區界圖資 |
| **地址/門牌** | ✅ | 門牌檢索 API（需申請） |

## 操作方式

1. 進入頁面瀏覽服務清單
2. 選擇「免申請服務」或「需申請服務」
3. 查看各服務的技術文件
4. 下載「網路服務介接申請書」
5. 備函申請（需申請服務）

## 憑證需求

| 項目 | 需求 |
|------|------|
| 瀏覽 API 文件 | **不需要**登入 |
| 使用免申請服務 | **不需要**申請 |
| 使用需申請服務 | **需備函申請** |

## API / 開放資料狀況

### 免申請服務（Open to All）

| 類型 | 數量 | 說明 |
|------|------|------|
| WMTS 圖資服務 | 多種 | 臺灣通用電子地圖、國土利用現況調查成果圖等 |
| WMS 圖資服務 | 多種 | 基本地形圖、行政區界圖等 |
| 開放 API | 22 項 | 不限對象 |
| 圖台 API | 多項 | 不限對象 |

**主要免申請端點**：
```
WMTS: https://wmts.nlsc.gov.tw/wmts
WMS:  https://wms.nlsc.gov.tw/wms
```

### 需申請服務（Restricted）

| 類型 | 數量 | 申請資格 |
|------|------|----------|
| WFS 向量圖資 | 18 種 | 政府機關、學術單位 |
| API 服務 | 27 項 | 依服務類型不同 |

**關鍵需申請 API**：

| API 名稱 | 功能 | 申請資格 |
|----------|------|----------|
| **地籍圖磚 WMTS** | 有地號標註的地籍圖 | 政府機關、國營機構、學術單位 |
| **地籍 API** | 指定地號查詢地籍圖 | 同上 |
| **地籍圖 API** | 取得指定條件地籍圖 | 同上 |
| **門牌檢索 API** | 門牌模糊檢索 | 同上 |
| **全國門牌地址定位服務** | 地址轉座標 | 同上 |
| **路徑規劃 API** | 導航路徑 | 政府機關、國營機構、學術單位、**民營機構** |

### 民營機構可申請的 API

根據政府服務網資訊，民營機構僅能申請：
- 門牌 API
- 路徑規劃 API

### 申請流程

1. 至本頁面「下載專區」下載申請書
2. 填寫申請書（免用印）
3. 備函送至：內政部國土測繪中心（408281 臺中市南屯區黎明路2段497號4F）
4. 3 個工作天內通知審查結果
5. 聯絡窗口：圖資應用推廣科 林先生 (04)22522966#310 / m6@mail.nlsc.gov.tw

### 技術規格

| 規格 | 支援 |
|------|------|
| OGC WMS | 1.1.1 / 1.3.0 |
| OGC WMTS | 1.0.0 |
| OGC WFS | 1.0.0 / 1.1.0 / 2.0.0 |
| REST API | JSON / XML |
| 座標系統 | EPSG:3826（TWD97）/ EPSG:4326（WGS84） |

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| **地籍圖磚** | 可在產品地圖上顯示地籍圖層 |
| **門牌定位 API** | 地址→座標→地號 的關鍵鏈路 |
| **地籍 API** | 地號→地籍圖形/屬性 |
| **免費底圖** | 通用電子地圖可作為產品底圖 |
| 不動產說明書 | 可補充地籍圖、土地使用分區圖 |

## 限制與注意事項

1. **地籍相關 API 限政府機關/學術單位申請**，民間企業難以取得
2. 民營機構僅能申請門牌 API 與路徑規劃 API
3. WFS 向量資料僅限申請單位內網使用
4. 需備函申請，流程約需 1-2 週
5. SSL 憑證有問題
