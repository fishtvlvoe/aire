# 內政部不動產成交案件實際資訊資料供應系統（實價登錄）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://plvr.land.moi.gov.tw/Main |
| 所屬機關 | 內政部地政司 |
| 系統名稱 | 內政部不動產成交案件實際資訊資料供應系統 |
| 類型 | 實價登錄資料申請/下載平台 |

## 功能概述

提供不動產成交案件實際資訊（實價登錄）的電子資料申請服務。用戶可透過本系統申請下載特定條件的實價登錄資料，包含完整地號與門牌資訊。系統自 110 年 7 月 1 日起提供完整地號與門牌之不動產成交資訊個案查詢。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 支援完整地號查詢 |
| **建號** | ⚠️ 間接 | 透過門牌或地號關聯查詢 |
| **地段** | ✅ | 可透過行政區+地段篩選 |
| **地址/門牌** | ✅ | 支援完整門牌查詢 |

## 操作方式

1. 進入系統後需先**登入**（自然人憑證或帳號密碼）
2. 選擇「不動產成交案件實際資訊資料申請」
3. 設定查詢條件：縣市、鄉鎮市區、地段、門牌、交易期間等
4. 提交申請後系統產製資料檔案供下載
5. 有**計費機制**（依資料筆數計費）

## 憑證需求

| 項目 | 需求 |
|------|------|
| 登入 | **需要**（自然人憑證或註冊帳號） |
| 資料申請 | **需要**登入 |
| 計費 | 依資料量計費 |

## API / 開放資料狀況

- **本系統無公開 API**：需透過網頁介面人工申請
- 相關開放資料請見同網域的 **DownloadOpenData** 頁面（另見 `09-plvr-opendata.md`）
- 實價登錄另有公開查詢網站：https://lvr.land.moi.gov.tw/（無需登入，可查詢但無法批次下載）

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| 實價登錄資料 | 可取得特定地號/門牌的歷史成交價格 |
| 不動產說明書 | 可補充「周邊實價行情」章節 |

## 限制與注意事項

1. **需登入且計費**，不適合自動化批量查詢
2. 資料申請有處理時間，非即時取得
3. 若需免費開放資料，請使用 `DownloadOpenData` 頁面
4. SSL 憑證有問題，介接時可能需設定忽略憑證驗證

## 相關連結

- 開放資料下載：https://plvr.land.moi.gov.tw/DownloadOpenData
- 實價登錄查詢（免登入）：https://lvr.land.moi.gov.tw/
