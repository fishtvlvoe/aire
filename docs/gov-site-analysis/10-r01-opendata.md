# 公有土地資料供應開放資料平台

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://easymap.moi.gov.tw/R01OpenData/Index |
| 所屬機關 | 內政部地政司 |
| 系統名稱 | 公有土地資料供應 |
| 類型 | 開放資料查詢/下載平台 |

## 功能概述

提供公有土地資料查詢與下載服務。公有土地是指各級政府機關持有之土地，本系統開放部分資料供各界查詢使用。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 可查詢公有土地地號 |
| **建號** | ⚠️ 間接 | 公有土地以土地為主 |
| **地段** | ✅ | 可透過行政區查詢 |
| **地址/門牌** | ⚠️ 間接 | 可透過地段查詢 |

## 操作方式

1. 進入系統
2. 可登入（憑證或非憑證）或使用開放查詢功能
3. 設定查詢條件（縣市、鄉鎮、地段等）
4. 查詢結果可線上瀏覽或下載

## 憑證需求

| 項目 | 需求 |
|------|------|
| 開放查詢 | **不需要**登入 |
| 進階下載 | 可能需要登入 |

## API / 開放資料狀況

### 開放資料規格

| 項目 | 說明 |
|------|------|
| 格式 | 網頁表格、可能提供 CSV/XML |
| 費用 | 免費 |

### 資料內容

公有土地資料欄位通常包含：
- 管理機關
- 縣市、鄉鎮市區
- 地段、地號
- 面積
- 使用分區/編定
- 公告現值/地價

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| 公有土地標示 | 可查詢標的物是否為公有土地 |
| 管理機關 | 確認土地管理機關 |

## 限制與注意事項

1. 公有土地資料更新頻率較低
2. 部分資料可能不完整
3. SSL 憑證有問題
