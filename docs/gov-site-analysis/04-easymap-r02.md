# 地籍圖資網路便民服務系統（R02 舊版）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://easymap.moi.gov.tw/R02/Index |
| 所屬機關 | 內政部資訊中心（系統維運）/ 內政部地政司（資料） |
| 系統名稱 | 地籍圖資網路便民服務系統（R02） |
| 類型 | WebGIS 圖台（OpenLayers） |

## 功能概述

提供全國土地基本資料庫查詢服務，民眾可使用**地號、建物門牌或坐標**等方式快速查詢土地參考位置，或查看附近空間地標資訊，同時提供土地簡單的面積、公告土地現值、公告地價等資訊。

系統將地籍圖與衛星影像、電子地圖等圖資進行套合。這是**免費圖資查詢系統**。

## 查詢能力矩陣

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 支援完整地段地號查詢 |
| **建號** | ✅ | 支援建號查詢 |
| **地段** | ✅ | 先選縣市→鄉鎮→地段 |
| **地址/門牌** | ✅ | 支援門牌地址查詢，可反查地建號 |

## 操作方式

### 地號查詢
1. 選擇縣市、鄉鎮市區
2. 選擇地段（段/小段）
3. 輸入地號（可輸入母號或母子號，如 `0012` 或 `0012-0000`）
4. 系統於地圖定位並顯示地籍圖形

### 門牌查詢
1. 選擇縣市、鄉鎮市區
2. 輸入路名或選擇道路
3. 輸入巷、弄、號
4. 系統回傳門牌列表，點選後定位並顯示對應地號/建號

## 憑證需求

| 項目 | 需求 |
|------|------|
| 查詢 | **不需要**登入，完全免費 |
| 資料下載 | 無需登入 |

## API / 開放資料狀況

### 內部 API（從 JavaScript 原始碼分析）

系統前端使用 OpenLayers，透過 AJAX 與後端溝通。發現以下 API 端點：

| API | 說明 |
|-----|------|
| `Map_json_getMaxMinLandNo` | 取得地段內最大/最小地號 |
| `Door_json_getDoorList` | 門牌查詢列表 |

### 請求範例（地號查詢）

```javascript
// 地號查詢參數
{
  office: "辦公室代碼",
  sectNo: "地段代碼",
  qryResult: "M2"
}
```

### 請求範例（門牌查詢）

```javascript
// 門牌查詢參數
{
  city: "縣市代碼",
  area: "鄉鎮代碼",
  road: "道路名稱",
  doorPlate: "門牌號",
  doorPlateType: "A" | "B",  // A=地政門牌, B=全國門牌定位
  lane: "巷",
  alley: "弄",
  no: "號"
}
```

### Token 機制

系統使用 `loadToken()` 函數取得動態 Token，Token 與 session 綁定。

## 對 AIRE 的潛在價值

| 價值項目 | 說明 |
|----------|------|
| **地號→門牌對照** | 這是核心功能！輸入地號可取得對應門牌，反之亦然 |
| **建號查詢** | 可查詢建物建號及其對應土地 |
| **地籍圖形** | 可取得土地坵形圖形（GeoJSON/向量） |
| **公告現值/地價** | 提供土地基本價格資訊 |
| 不動產說明書 | 可補充「地籍資料」與「建物資料」章節 |

## 限制與注意事項

1. **無官方公開 API 文件**：API 需從前端 JS 逆向工程取得
2. Token 有時效性，需搭配 session 使用
3. 地籍圖資料與地政事務所現況存在時間差
4. SSL 憑證有問題
5. 系統為舊版介面（R02），新版請見 Z10Web / W10Web
