# 地籍圖資網路便民服務系統（主入口）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://easymap.moi.gov.tw/Index |
| 所屬機關 | 內政部資訊中心 / 內政部地政司 |
| 系統名稱 | 地籍圖資網路便民服務系統 |
| 類型 | 入口導引頁 |

## 功能概述

此網址為地籍圖資網路便民服務系統的**主入口**，會自動導向至新版圖台（Z10Web）。實際功能與 Z10Web / W10Web 相同。

從 resiliance 監測資料可見，此入口會 302 導向至 `https://easymap.moi.gov.tw/Z10Web/Index`。

## 查詢能力矩陣

與 Z10Web 相同：

| 查詢條件 | 是否支援 | 說明 |
|----------|----------|------|
| **地號** | ✅ | 導向 Z10Web 查詢 |
| **建號** | ✅ | 導向 Z10Web 查詢 |
| **地段** | ✅ | 導向 Z10Web 查詢 |
| **地址/門牌** | ✅ | 導向 Z10Web 查詢 |

## 操作方式

進入後自動導向新版圖台，操作方式請見 `06-easymap-z10.md`。

## 憑證需求

與 Z10Web 相同，無需登入。

## API / 開放資料狀況

此頁面僅為入口，無獨立 API。

## 對 AIRE 的潛在價值

此為入口頁，實際價值請參考 Z10Web / W10Web 分析。

## 限制與注意事項

1. 僅為導向頁面
2. SSL 憑證有問題
