## 🔑 解決「地址→地號→建號」的關鍵 API

### 1. MOI_API_036 門牌查建號服務 ⭐ 最核心

| 項目 | 內容 |
|------|------|
| **民間價格** | **免費，需帳號驗證** |
| **功能** | 地址 → 建號（含地段、事務所代碼） |
| **介面** | `QueryByAddress` |

**輸入參數：**
| 參數 | 必填 | 說明 |
|------|------|------|
| CITY | 必填 | 縣市代碼（1 碼） |
| ADDRESS | 必填 | 完整地址（需含縣市、鄉鎮、路街巷、門牌號，段/樓用中文數字） |

**回傳欄位：**
| 欄位 | 說明 |
|------|------|
| UNIT | 地政事務所代碼 |
| SEC | 段代碼（4 碼） |
| NO | 建號 |
| ADDRESS | 建物門牌 |

**限制：** 單次查詢上限 **1 筆**

> ⚠️ 此 API 需要 COP 平台帳號驗證才能呼叫

---

### 2. MOI_API_015 建號資料服務 ⭐ 核心

| 項目 | 內容 |
|------|------|
| **民間價格** | **每筆地號 1 元** |
| **功能** | 地號 → 建號列表 |
| **介面** | `QueryByLandNo` |

**輸入參數：**
| 參數 | 必填 | 說明 |
|------|------|------|
| UNIT | 必填 | 事務所代碼（2 碼） |
| SEC | 必填 | 段代碼（4 碼） |
| NO | 必填 | 地號（8 碼） |

**回傳欄位：**
| 欄位 | 說明 |
|------|------|
| NO | 地號 |
| BNO | 建號 |

**限制：** 單次查詢上限 **25 筆**

---

### 3. MOI_API_007 地號資料服務

| 項目 | 內容 |
|------|------|
| **民間價格** | **依地段每段 10 元** |
| **功能** | 地段/座標 → 地號列表 |

**介面 1：`QueryBySec`（以地段查詢）**
| 參數 | 必填 | 說明 |
|------|------|------|
| UNIT | 必填 | 事務所代碼（2 碼） |
| SEC | 必填 | 段代碼（4 碼） |
| ZONE/TYPE/OWNTYPE/AREA... | 擇一 | 使用分區、面積區間等篩選 |

**介面 2：`QueryByXY`（以座標查詢）** ⭐ 重要
| 參數 | 必填 | 說明 |
|------|------|------|
| X | 必填 | X 坐標 |
| Y | 必填 | Y 坐標 |
| SRS | 選填 | WGS84 / TWD97 / TWD67 等 |

**回傳：** CITY, TOWN, UNIT, SEC, NO（完整地號資訊）

**限制：** 單次上限 10 筆

---

### 4. MOI_API_012 全國土地基本資料庫代碼資料服務

| 項目 | 內容 |
|------|------|
| **民間價格** | **免費** |
| **功能** | 提供所有代碼對照表（縣市、鄉鎮、事務所、地段等） |

**關鍵介面：**
| 介面 | 功能 | 輸入 |
|------|------|------|
| `QueryCity` | 查縣市代碼 | 無 |
| `QueryTown` | 查鄉鎮代碼 | CITY |
| `QueryUnit` | 查事務所代碼 | CITY |

> 其他 API 所需的 UNIT/SEC/CITY 等代碼，都從這裡取得

---

### 5. MOI_API_011 新舊地建號轉換服務

| 項目 | 內容 |
|------|------|
| **民間價格** | **免費** |
| **功能** | 新舊地號/建號互相轉換 |

**介面：**
- `QueryLandNo`: 新舊地號轉換（UNIT, SEC, NO, TYPE=N/O）
- `QueryBuildNo`: 新舊建號轉換（UNIT, SEC, NO, TYPE=N/O）

---

### 6. MOI_API_013 地段資料服務

| 項目 | 內容 |
|------|------|
| **民間價格** | **免費，需帳號驗證** |
| **功能** | 查詢地段代碼與名稱對照 |

## 完整查詢鏈路設計

### 鏈路 A：地址 → 建號（最便宜路徑）

```
地址（如：新北市新莊區中央路 123 號）
    │
    ├─→ MOI_API_012 QueryCity → 縣市代碼（新北市 = ?）
    │
    └─→ MOI_API_036 QueryByAddress(CITY, ADDRESS) 
            → {UNIT, SEC, NO, ADDRESS}
            → 得到建號 + 地段代碼 + 事務所代碼
    
成本：免費（只需 COP 帳號）
```

### 鏈路 B：地址 → 地號 → 建號

```
地址
    │
    ├─→ MOI_API_036 QueryByAddress → 建號 + UNIT + SEC
    │
    └─→ MOI_API_015 QueryByLandNo(UNIT, SEC, 地號)
            → 得到該地號下的所有建號列表

成本：每筆地號 1 元
```

### 鏈路 C：座標 → 地號（當只有 GPS 座標時）

```
GPS 座標 (X, Y)
    │
    └─→ MOI_API_007 QueryByXY(X, Y, SRS)
            → {CITY, TOWN, UNIT, SEC, NO}

成本：依地段每段 10 元
```

## 前提條件

**使用上述 API 的前提：必須有 COP 平台帳號**

### COP 帳號申請方式

1. 至 https://cop.land.moi.gov.tw/ 註冊會員
2. 申請「民間企業」資格
3. 通過審核後取得帳號密碼
4. 部分付費 API 需儲值點數

## 與其他來源比較

| 來源 | 地址→建號 | 地號→建號 | 費用 | 前提 |
|------|:---------:|:---------:|:----:|------|
| **COP MOI_API_036** | ✅ | - | 免費 | COP 帳號 |

> COP 的優勢：**官方 API、穩定、有文件、即時查詢**
> COP 的劣勢：**需要帳號申請、部分功能付費**

## 對 AIRE 的建議

### 最佳組合策略

1. **申請 COP 帳號**（必要前提）
2. **MOI_API_036** 做地址→建號（免費）
3. **MOI_API_015** 做地號→建號（1 元/筆，成本極低）
4. **MOI_API_012** 做代碼查詢（免費）
5. 搭配 **實價登錄 Open Data** 做離線比對（補充歷史資料）

### 如果沒有 COP 帳號的替代方案

- 逆向工程 easymap（Z10Web/W10Web/R02）前端 AJAX
- 使用實價登錄 Open Data 建立本機門牌-地號-建號對照庫
- 申請 TGOS API Key 做地址→座標，再搭配地籍圖 WMS 人工判讀
