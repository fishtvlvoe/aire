# 真實物件前查測試資料

這份清單是 Fish 提供的真實物件 fixture，用來測試 AIRE 的地址優先前查流程。

使用邊界：

- 只用於簽約前免費前查、物調表草稿、候選地段地號/建號對標。
- 不可在未取得明確確認前直接打 COP 正式謄本。
- EasyMap Z10Web 是免費前查 primary source；R02 只可作為 fallback 或交叉檢查，不是第一優先。
- 便民系統 / EasyMap 只作為候選 discovery，不是正式權威謄本來源。
- E2E 測試應記錄每筆輸入、查詢狀態、候選資料、錯誤原因與費用；前查費用必須為 0。

## 驗收指令

本機 dev server 啟動後可跑：

```bash
E2E_BASE_URL=http://localhost:1420 pnpm exec playwright test e2e/real-property-fixtures-free-discovery.spec.ts --reporter=line
```

測試輸出：

- `artifacts/smoke/real-property-fixtures-free-discovery.json`

這個 artifact 是驗收用證據，包含每筆 fixture 的狀態、候選數、第一筆候選、錯誤訊息與費用欄位。
