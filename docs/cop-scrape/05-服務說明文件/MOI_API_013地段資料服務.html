MOI_API_013地段資料服務

1.以鄉鎮查詢：QueryByTown

1.1.查詢參數
參數名稱 必選填 說明
CITY 必填 縣市代碼，字元長度為1
TOWN 必填 鄉鎮代碼，字元長度為2
FILTER 選填 地段關鍵字，字元長度限制為1~5字
ENABLE 選填 設定有效地段的輸出
【0(預設值)：全部列出，1：僅輸出有效地段】
➔單次查詢上限10筆

1.2.輸出欄位
地段：SECTION
回傳欄位名稱 資料欄位中文
UNIT 地政事務所代碼
NAME 地段名稱
SEC 地段代碼
COMMENT 備註說明

2.以事務所查詢：QueryByUnit

2.1.查詢參數
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
FILTER 選填 段名關鍵字，字元長度限制為1~5字
ENABLE 選填 設定有效地段的輸出
【0(預設值)：全部列出，1：僅輸出有效地段】
➔單次查詢上限10筆

2.2.輸出欄位
地段：SECTION
回傳欄位名稱 資料欄位中文
NAME 地段名稱
SEC 地段代碼
COMMENT 備註說明
