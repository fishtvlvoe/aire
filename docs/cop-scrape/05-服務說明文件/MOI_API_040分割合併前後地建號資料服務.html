MOI_API_040分割合併地建號資料服務

1.查詢特定時段內分割(或合併)之地建號

1.1.以地段查詢：QueryBySEC
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
TYPE 必填 查詢條件類型，S：分割，M：合併
STARTDATE 選填 查詢區段起始日期，格式：民國年月日(0980123)
ENDDATE 選填 查詢區段結束日期，格式：民國年月日(1031201)
ENABLE 選填 有效資料的輸出，0(預設值)：全部，1：僅輸出有效
➔單次僅能輸入一組參數JSON結構，輸入參數包含包含地政事務所代碼、地段代碼、時間區段、分割(或合併)、設定有效資料的輸出等，陣列的長度上限為1筆

1.2輸出欄位

分割合併地建號 DIVISIONMERGE
回傳欄位名稱 資料欄位中文
RDATE 登記日期
RECPYEAR 收件年期
RECP 收件字
RECPNO 收件號
BESEC 分割後(合併前)段小段
BEBNO 分割後(合併前)地建號
AFSEC 分割前(合併後)段小段
AFNO 分割前(合併後)地建號
FLAG 分割合併註記，S：分割，M：合併
COMMENT 資料已無使用註記，Y：已無使用

2.查詢分割合併前後歷次地建號

2.1.以地號查詢：QueryLandNo
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 地號，字元長度為8
➔單次僅能輸入一組參數JSON結構，輸入參數包含包含地政事務所代碼、地段代碼、地號的輸出等，陣列的長度上限為1筆

2.2.以建號查詢：QueryBuildingNo
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 建號，字元長度為8
➔單次僅能輸入一組參數JSON結構，輸入參數包含包含地政事務所代碼、地段代碼、地號的輸出等，陣列的長度上限為1筆

2.輸出欄位

分割合併地建號 DIVISIONMERGE

RECPYEAR 收件年期
RECP 收件字
RECPNO 收件號
REASON 登記原因
RDATE 登記日期
分割DIVISION(合併MERGE)前後地建號BEFORE/AFTER
回傳欄位名稱 資料欄位中文
UNIT 地政事務所代碼
SEC 分割後(合併前)段小段
NO 分割後(合併前)地建號
