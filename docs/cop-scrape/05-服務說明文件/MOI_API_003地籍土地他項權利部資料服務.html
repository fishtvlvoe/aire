MOI_API_003地籍土地他項權利部資料服務

1.查詢參數

1.1.依所有權登記次序查詢：QueryByRegisterNo
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 地號，字元長度為8
RNO 必填 所有權登記次序，字元長度為4
➔單次查詢條件上限25筆

1.2.依筆數查詢：QueryByLimit
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 地號，字元長度為8
OFFSET 必填 起始索引號，請填大於0之正整數
LIMIT 必填 回傳資料筆數，請填正整數，上限值為100
➔單次查詢條件上限1筆
➔109年度該介面回傳欄位新增TOTALCOUNT總共資料筆數

1.3.依收件年字號查詢：QueryByReceiveNO
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 地號，字元長度為8
YEAR 必填 收件年期，字元長度為3
RECEIVENO1 必填 收件字,字元長度為4
RECEIVENO2 必填 收件號,字元長度為6
➔單次查詢條件上限25筆
