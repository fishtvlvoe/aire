MOI_API_039公有土地開放資料服務

1.查詢參數

1.1.以鄉鎮查詢：QueryByTown
參數名稱 必選填 說明
CITY 必填 縣市代碼，字元長度為1
TOWN 必填 鄉鎮代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
➔單次僅能輸入一組參數JSON結構
➔單次查詢條件上限25筆

1.2.以地政事務所查詢：QueryByUnit
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
➔單次僅能輸入一組參數JSON結構
➔單次查詢條件上限25筆

No 地號

所有權人 OWNER

OwnerType 所有權人類別
RightType 權利範圍類別

Numerator 權利範圍分子
DLPrice 申報地價
ManagerName 管理者名稱
