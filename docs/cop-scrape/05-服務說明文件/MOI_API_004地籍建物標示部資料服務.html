MOI_API_004地籍建物標示部資料服務

1.以建號查詢：QueryByBuildNo

1.1.查詢參數
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 建號，字元長度為8
➔單次查詢上限25筆

 

1.2.輸出欄位
建物標示部：BLDGREG
回傳欄位名稱 資料欄位中文
RECEIVEYEAR 收件年期
RECEIVENO1 收件字
RECEIVENO2 收件號
RDATE 登記日期
REASON 登記原因(※代碼06)
AREA 建物總面積
BNUMBER 建物門牌
PURPOSE 主要用途
MATERIAL 主要建材
BUILDINGFLOOR 建物層數
COMPLETEDATE 建築完成日期
※相關代碼對照請參閱本站服務目錄>搜尋MOI_API_012全國土地基本資料庫代碼資料服務，參考其服務介面與回傳欄位說明。

 

建物坐落地號：LANDNO
回傳欄位名稱 資料欄位中文
SUBSECTION 基地段小段
LANDNO 基地地號

 

主建物其他登記事項：OTHERREG
回傳欄位名稱 資料欄位中文
NUMBER 序號
CATEGORY 其他登記事項代碼(※代碼30)
CONTENT 其他登記事項內容
※相關代碼對照請參閱本站服務目錄>搜尋MOI_API_012全國土地基本資料庫代碼資料服務，參考其服務介面與回傳欄位說明。

 

建物分層或附屬建物：FLOORACC
回傳欄位名稱 資料欄位中文
FID_ABID 分層或附屬建物識別
FPUR_ABPUR 層次或附屬建物用途
FAREA_ABAREA 層次或附屬建物面積

 

共有部分：SHAREDAREA
回傳欄位名稱 資料欄位中文
SSUBSECTION 共有部分段小段
SBNO 共有部分建號
SAREA 共有部分面積
DENOMINATOR 權利範圍分母
NUMERATOR 權利範圍分子

 

共有部分停車位：SHAREDPARK
回傳欄位名稱 資料欄位中文
PSNO 車位編號
PSDENOMINATOR 車位權利範圍分母
PSNUMERATOR 車位權利範圍分子

 

共有部分其他登記事項：OTHERREG
回傳欄位名稱 資料欄位中文
NUMBER 其他登記事項序號
CATEGORY 其他登記事項代碼(※代碼30)
CONTENT 其他登記事項內容
