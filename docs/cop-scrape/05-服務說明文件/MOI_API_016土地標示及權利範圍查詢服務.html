MOI_API_016土地標示及權利範圍

1.以地號查詢：QueryByLandNo

1.1.查詢參數
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 地號，字元長度為8
RNO 擇一選填 所有權登記次序，字元長度為4
➔單次查詢上限25筆
➔選填的參數需擇一填寫

1.2.輸出欄位
土地標示及權利範圍：LANDPOWERS
回傳欄位名稱 資料欄位中文
RNO 登記次序
RDATE 土地標示部登記日期
REASON 登記原因(※代碼06)
AREA 登記面積
RDATE 所有權登記日期
RIGHT 權利範圍類別(※代碼15)
NUMERATOR 所有權分子
DENOMINATOR 所有權分母
※相關代碼對照請參閱本站服務目錄>搜尋MOI_API_012全國土地基本資料庫代碼資料服務，參考其服務介面與回傳欄位說明。
