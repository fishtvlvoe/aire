MOI_API_005地籍建物所有權部資料服務

1.查詢參數

1.1.依所有權登記次序查詢：QueryByRegisterNo
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 建號，字元長度為8
RNO 必填 所有權登記次序，字元長度為4
➔單次查詢條件上限25筆

1.2.依筆數查詢：QueryByLimit
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
NO 必填 建號，字元長度為8
OFFSET 必填 起始索引號，請填大於0之正整數
LIMIT 必填 回傳資料筆數，請填正整數，上限值為100
➔單次查詢條件上限1筆
➔109年度該介面回傳欄位新增TOTALCOUNT總共資料筆數

2.輸出欄位

建物所有權部：BLDGOWNERSHIP
回傳欄位名稱 資料欄位中文
OWRNO 所有權登記次序
RECEIVEYEAR 收件年期
RECEIVENO1 收件字
RECEIVENO2 收件號
RDATE 登記日期
REASON 登記原因(※代碼06)
REASONDATE 登記原因發生日期
RIGHT 權利範圍類別(※代碼15)
DENOMINATOR 權利範圍分母
NUMERATOR 權利範圍分子
※相關代碼對照請參閱本站服務目錄>搜尋MOI_API_012全國土地基本資料庫代碼資料服務，參考其服務介面與回傳欄位說明。

權利人：OWNER
回傳欄位名稱 資料欄位中文
LTYPE 類別(※代碼09)
LID 統一編號
LNAME 姓名
LADDR 地址
※權利人資訊僅提供類別為「國有」、「省市有」、「縣市有」、「鄉鎮市有」時提供，其餘類別則以null呈現。

相關他項權利部：OTHERRIGHTS
回傳欄位名稱 資料欄位中文
ORNO 他項權利登記次序

其他登記事項：OTHERREG
回傳欄位名稱 資料欄位中文
NUMBER 其他登記事項序號
CATEGORY 其他登記事項代碼(※代碼30)
CONTENT 其他登記事項內容
※相關代碼對照請參閱本站服務目錄>搜尋MOI_API_012全國土地基本資料庫代碼資料服務，參考其服務介面與回傳欄位說明。
