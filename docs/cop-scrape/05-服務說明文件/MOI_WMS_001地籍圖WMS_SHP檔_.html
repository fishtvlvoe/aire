MOI_WMS_001地籍圖WMS(SHP檔)

一、 服務說明

本服務以土地(宗地)為單位，依地號查詢取得地籍圖WMS(Web Map Service；網路地圖服務，是一種最簡單快速的網路產圖服務，欲瞭解WMS服務類型與原理請先參考平台服務類型若欲進一步了解WMS標準格式相關規格請參閱OGC網站 。

本服務後端以Shapefile檔案形式透過GIS server發布為OGC標準WMS服務，服務更新頻率配合每季更新Shapefile資料頻率，詳細服務介接資訊可參考服務引用流程說明。

二、 服務規格

(一) HTTP HEADER資訊
名稱 說明
UserName 應用系統識別碼（使用者帳號）
Password 應用系統密碼（使用者密碼）
  • (1) UserName：為應用系統識別碼（政府機關）或使用者帳號（付費使用者），用以驗證平台使用者資訊。
  • (2) Password：為應用系統密碼（政府機關）或使用者密碼（付費使用者），用以驗證平台使用者資訊。

(二) 介面設計

本平台目前提供的WMS服務支援兩個操作介面，包括GetCapabilities、GetMap，詳細查詢參數與回傳結果說明規格如下：

  • 1、Getcapabilites

    此方法是取得WMS服務基本資訊的主要方法，其格式為XML，內容包括圖層名稱、坐標系統、圖形範圍坐標、支援圖檔格式等等。

    ※請先使用GetCapabilities取得您查詢地號的圖形範圍坐標（bbox），再進一步將bbox代入GetMap之必要參數。

    (1) 查詢參數

    參數名稱 條件 參數值 說明
    service 必填 WMS 服務性質
    request 必填 GetCapabilities 服務要求
    UNIT 必填 可依需求自行設定 事務所代碼，字元長度為2
    SEC 必填 可依需求自行設定 段代碼，字元長度為4
    NO 必填 可依需求自行設定 地號，字元長度為8

    (2) 輸出資料

  • 2、GetMap

    此方法是取得WMS圖形的方法，其輸出格式依據引用端使用的參數來提供。必要參數如以下所示。

    (1) 查詢參數

    參數名稱 條件 參數值 說明
    service 必 WMS 服務性質
    version 必 以預設值即可 服務版本
    request 必 GetMap 服務要求
    layers 必 值為地政事務所代碼、段代碼、地號組合，例：AA000100010000 依據GetCapabilities LayerName內容設置
    bbox 必 (左上X坐標,左上Y坐標,右下X坐標,右下Y坐標) 縣市圖徵左上角及右下角坐標
    srs 必 epsg:4326、epsg:3825、epsg:3826、epsg:3827、epsg:3828 坐標系統參數
    format 必 格式：image/影像格式 (png、jpeg、gif) 顯示格式 (參考WMS規範)
    styles 選 提供default、labeled兩種樣式，default僅繪製地籍圖，labeled則額外繪製地號於圖形上 顯示圖徵型態
    width 選 可依需求自行設定 顯示圖徵範圍寬度
    height 選 可依需求自行設定 顯示圖徵範圍高度
    UNIT 必 依需求自行設定地政事務所代碼 協作平台必要參數
    SEC 必 依需求自行設定段代碼 協作平台必要參數
    NO 必 依需求自行設定地號 協作平台必要參數
