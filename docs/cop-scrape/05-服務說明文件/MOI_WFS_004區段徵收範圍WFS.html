MOI_WFS_004區段徵收空間範圍WFS

一、 服務說明

區段徵收空間範圍WFS (Web Feature Service；網路圖徵服務)查詢服務以縣市(代碼)、案件類型(代碼)、案件狀態(代碼)等條件，查詢取得區段徵收範圍資訊，引用介接參數之坐標系統可為WGS84。欲瞭解WFS服務類型與原理請先參考平台服務類型，若欲進一步了解WFS標準格式相關規格請參閱OGC網站，詳細服務介接資訊可參考服務引用流程說明。

二、 服務規格

(一) HTTP HEADER資訊
名稱 說明
UserName 應用系統識別碼（使用者帳號）
Password 應用系統密碼（使用者密碼）
  • (1) UserName：為應用系統識別碼（政府機關）或使用者帳號（付費使用者），用以驗證平台使用者資訊。
  • (2) Password：為應用系統密碼（政府機關）或使用者密碼（付費使用者），用以驗證平台使用者資訊。

(二) 介面設計

本平台目前提供的WFS服務支援兩個操作介面，包括GetCapabilities、GetFeature，詳細查詢參數與回傳結果說明規格如下：

  • 1、Getcapabilites

    此方法是取得WFS服務基本資訊的主要方法，其格式為XML，內容主要描述該服務目前提供的圖層資訊。

    (1) 查詢參數

    參數名稱 條件 參數值 說明
    service 必填 WMS 服務性質
    request 必填 GetCapabilities 服務要求
    CITY 必填 可依需求自行設定 縣市代碼，字元長度為1
    STATUS 選填 可依需求自行設定 辦理狀態，0:規劃中(辦理中)，1:辦理完成，不填則全部

    (2) 輸出資料

  • 2、GetFeature

    此方法是取得圖層的向量資料的主要方法，而向量資料則是以GML格式進行描述，必要參數如以下所示。

    (1) 查詢參數

    參數名稱 條件 參數值 說明
    service 必 WFS 服務性質
    version 必 以預設值即可 服務版本
    request 必 GetFeature 服務要求
    typeName 必 值為區段徵收案號，例：TJS2479929227 依據GetCapabilities FeatureTypeName內容設置
    srs 必 epsg:4326(預設值)、epsg:3826、epsg:3828 坐標系統參數
