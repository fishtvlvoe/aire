MOI_API_007地號資料服務

1.以地段查詢：QueryBySec

1.1.查詢參數
參數名稱 必選填 說明
UNIT 必填 事務所代碼，字元長度為2
SEC 必填 段代碼，字元長度為4
ZONE 擇一選填 使用分區
TYPE 擇一選填 使用地類別
OWNTYPE 擇一選填 公私別【0:私有、1:公有、2:公私共有】
MANAGERLID 擇一選填 管理機關統一編號，字元長度為8
AREA 選填值域區間 土地面積，單位平方公尺，格式：最小/最大(30/100)
CURRENTVALUE 選填值域區間 公告現值，單位元/平方公尺，格式：最小/最大(15000/30000)
DECLAREDVALUE 選填值域區間 公告地價，單位元/平方公尺，格式：最小/最大(15000/30000)
➔單次查詢上限10筆
➔選填的參數同時只能使用一個，若有多個則以順序決定

1.2.輸出欄位
地號：LAND
回傳欄位名稱 資料欄位中文
NO 地號

2.以坐標查詢：QueryByXY

2.1.查詢參數
參數名稱 必選填 說明
X 必填 X坐標
Y 必填 Y坐標
SRS 選填 坐標系統【WGS84、TWD97、TWD67、EPSG:4326、EPSG:3825、EPSG:3826、EPSG:3827、EPSG:3828】
➔單次查詢上限10筆

2.2.輸出欄位
地號：LAND
回傳欄位名稱 資料欄位中文
CITY 縣市代碼
TOWN 鄉鎮市區代碼
UNIT 事務所代碼
SEC 段代碼
NO 地號
