MOI_WFS_003圖幅接合地籍圖WFS

一、 服務說明

本服務以土地(宗地)為單位，依地號查詢取得地籍圖WFS(Web Feature Service；網路圖徵服務)，是將原始資料轉譯成GML供服務介接端使用，欲瞭解WFS服務類型與原理請先參考平台服務類型，若欲進一步了解WFS標準格式相關規格請參閱OGC網站，詳細服務介接資訊可參考服務引用流程說明。

二、 服務規格

(一) HTTP HEADER資訊
名稱 說明
UserName 應用系統識別碼（使用者帳號）
Password 應用系統密碼（使用者密碼）
  • (1) UserName：為應用系統識別碼（政府機關）或使用者帳號（付費使用者），用以驗證平台使用者資訊。
  • (2) Password：為應用系統密碼（政府機關）或使用者密碼（付費使用者），用以驗證平台使用者資訊。

(二) 介面設計

本平台目前提供的WFS服務支援兩個操作介面，包括GetCapabilities、GetFeature，詳細查詢參數與回傳結果說明規格如下：

  • 1、Getcapabilites

    此方法是取得WFS服務基本資訊的主要方法，其格式為XML，內容主要描述該服務目前提供的圖層資訊。

    (1) 查詢參數

    參數名稱 條件 參數值 說明
    service 必填 WMS 服務性質
    request 必填 GetCapabilities 服務要求
    LD 必填 AA 事務所代碼，字元長度為2
    SCNO 必填 0001 段代碼，字元長度為4
    PO 必填 00010000 地號，字元長度為8

    (2) 輸出資料

  • 2、GetFeature

    此方法是取得圖層的向量資料的主要方法，而向量資料則是以GML格式進行描述，必要參數如以下所示。

    (1) 查詢參數

    參數名稱 條件 參數值 說明
    service 必 WFS 服務性質
    version 必 以預設值即可 服務版本
    request 必 GetFeature 服務要求
    typeName 必 值為地政事務所代碼、段代碼、地號組合，例：AA000100010000 依據GetCapabilities FeatureTypeName內容設置
    srs 必 epsg:4326、epsg:3826、epsg:3828 坐標系統參數
    width 選 可依需求自行設定 顯示圖徵範圍寬度
    height 選 可依需求自行設定 顯示圖徵範圍高度
    LD 必 事務所代碼 AA
    SCNO 必 段代碼 0001
    PO 必 地號 00010000

    (2) 輸出資料
