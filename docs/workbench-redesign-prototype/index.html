AIRE Workbench 新版 UI 草稿

這組 HTML 只用來對齊版型與資訊密度，不代表最終實作細節。重點是先確認： 物件摘要 怎麼收、主工作區怎麼放大、以及 NT$20 的付費說明怎麼變透明。

頁面 01

欄位初審

上方摘要條 + 單欄主工作區。拿掉左側大型摘要欄。
  • 主區塊變寬
  • 摘要只保留一行核心數字
  • 適合作為主基底版型
 頁面 02

補件與現場

同一套 header，主區塊換成補件與現場確認內容。
  • 維持同一個摘要條
  • 主工作區可容納更寬的補件列表
 頁面 03

正式資料匯入

把付費查詢前的價值說明、查詢內容、差異說清楚。
  • 先說明免費前查 vs 正式查詢
  • 按鈕前先理解，不直接只有價錢
 頁面 04

物件資料總覽

把來源、資料等級、待補欄位集中到一頁。
  • reference / formal 明確標示
  • 適合檢查資料完整度
 頁面 05

PDF 檢查

看進 PDF 的內容有哪些、哪些還是參考資料。
  • 避免沒正式資料時誤認為正式版
  • 讓輸出前檢查更直接
 頁面 06

付費說明 Modal

專門看 NT$20 的說明方式，回答「拿到什麼、為什麼要付」。
  • 查詢項目
  • 取得資料
  • 計費說明
